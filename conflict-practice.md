## Conflict Practice

## My workflow prefrences

- I prefer rebasing feature branches for a clean linear history.  
- I resolve conflicts by combing the best of both changes
## Tools I use

- Cursor for editing
- Git CLI for version control
- GitHub for collab.  

## Lesson Learned

- Merge conflicts are normal and not scary
- Rebase rewrites history, so only use it on local branches
- Interactive rebase is pweorful for cleaning up work before sharing
